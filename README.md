# 🗂️ GitHub File Explorer

A modern file manager designed to enhance the GitHub repository browsing experience. This tool provides a user-friendly interface to navigate, manage, and explore files within GitHub repositories more efficiently.

---

## 🚀 Features

* **Intuitive Interface**: Navigate repositories with ease using a clean and modern UI.
* **File Previews**: Preview file contents directly within the explorer without the need to download them.
* **Search Functionality**: Quickly search for files and folders within large repositories.
* **Multi-Repository Support**: Manage and explore multiple repositories simultaneously.

---

## ⚙️ Installation

### Prerequisites

* **Node.js**: Ensure Node.js is installed on your system.
* **GitHub Personal Access Token**: Generate a personal access token from your GitHub account settings.

### Steps

1. Clone the repository:

```bash
git clone https://github.com/thiagofeijodev/github-file-explorer.git
cd github-file-explorer
```

2. Install dependencies:

```bash
npm install
```

3. Configure your GitHub token:

```bash
cp .env.example .env
```

Edit the `.env` file and add your GitHub personal access token.

4. Start the application:

```bash
npm start
```

---

## 🛠️ Usage

* Open the application in your browser.
* Authenticate using your GitHub account.
* Browse and manage your repositories using the intuitive interface.
